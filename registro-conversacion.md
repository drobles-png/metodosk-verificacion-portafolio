# Registro de conversación — Verificación de Portafolios Comerciales de Meta

Fecha: 2026-09-14

## Contexto

El usuario (dreyes@bakano.ec, agencia Bakano) solicitó ayuda para verificar
**portafolios comerciales de Meta Business Manager** de clientes, no carteras
financieras/de crédito. Se aportó como ejemplo una captura del portafolio
comercial "Karen López Armijos" (dominio `metodosk.ec`, ID de portafolio
`1840184922706204`), con estado **"Sin verificar"**.

## Resumen de la conversación

1. El usuario preguntó si había conocimiento sobre verificación de
   "portafolio comercial".
2. Se aclaró mediante preguntas que no se refería a cartera de crédito/ventas,
   sino al **Portfolio Comercial de Meta** (Business Manager/Business Suite).
3. El usuario definió el alcance: quiere una **metodología/checklist
   reutilizable** que Bakano pueda aplicar a múltiples clientes, no solo
   resolver un caso puntual.
4. Se investigó (WebSearch) el proceso actual de verificación de negocio de
   Meta: documentos aceptados, verificación de dominio, causas comunes de
   rechazo y tiempos de revisión.
5. Se creó el archivo
   [`METODOLOGIA-VERIFICACION-PORTAFOLIO-META.md`](./METODOLOGIA-VERIFICACION-PORTAFOLIO-META.md)
   en este mismo proyecto, con:
   - Prerrequisitos antes de iniciar el trámite.
   - Checklist paso a paso dentro de Meta Business Manager.
   - Tabla de causas de rechazo y cómo evitarlas.
   - Documentos aceptados por país (foco Ecuador).
   - Plantilla de seguimiento por cliente/portafolio.
   - Guía de próximos pasos según el estado (Sin verificar / En revisión /
     Verificado / Rechazado).
